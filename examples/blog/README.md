# Beispiel-Ordner

Ein Veröffentlichungsordner, wie ihn das Plugin erwartet: zwei veröffentlichte
Notizen, ein Entwurf und ein eigenes Stylesheet.

Zum Ausprobieren in den Vault kopieren, in den Einstellungen ein Konto auf
diesen Ordner zeigen lassen und **Veröffentlichung prüfen** ausführen. Der Plan
zeigt, was übertragen und was gelöscht würde, bevor irgendetwas passiert.
